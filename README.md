# Virtual Simulated Patients with Self-Refinement Mechanism

This repository contains prompt templates and supporting materials for the paper:

> **Virtual Simulated Patients for Medical Interviews Using Large Language Models with a Self-Refinement Mechanism to Suppress Excessive Responses**  
> Naoki Shindo and Masaki Uto  
> Presented at International Conference on Artificial Intelligence in Education (AIED) 2025

## Overview

This project provides the prompt templates used in our method for constructing Virtual Simulated Patients (VSPs) using large language models (LLMs). Our approach combines:

- **Question Category-aware Answering (QC-aware)**
- **Self-Refinement Mechanism** using LLM-as-agent

These mechanisms help suppress overly detailed responses while preserving fluency and relevance in medical interview scenarios.
